🛡️ How your files are kept secure

  • Encrypted at rest: every file is encrypted with AES-256-GCM before it reaches the disk. Files are stored under random names, and the encryption key is kept separate from the stored files — a copy of the file folder alone is unreadable ciphertext.
  • No passwords, ever: nobody has a password that could leak or be guessed. Login uses a one-time code / link sent to your email — it expires in 15 minutes, works exactly once, and requests are rate-limited.
  • Private by default: a file is visible only to its owner and the specific people it has been shared with. Every view and download is checked on the server — guessing a file's address returns nothing.
  • Scanned for viruses: every upload is scanned with ClamAV antivirus before it is stored; a file that fails the scan is rejected and never reaches the vault.
  • Integrity checked: a SHA-256 fingerprint is calculated when your file arrives and verified against the stored copy, so any corruption or tampering is detectable.
  • Encrypted in transit: access to this vault is over HTTPS only, so files and login codes are encrypted between your device and the server.
  • Fully audited: logins, uploads, downloads, shares, and deletions are recorded in an audit log reviewed by the vault administrator.
  • Access can be revoked instantly: if an account is disabled or a session is revoked, that access stops immediately — including for files already shared.

Hosted on a private server controlled by the vault owner — your files are not sold, scanned for advertising, or shared with third parties.
